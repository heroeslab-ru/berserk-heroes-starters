## ➕ Как добавить недостающий набор

Если вы заметили, что в репозитории нет какого-то набора:

1. Перейдите во вкладку [**Issues**](../../issues) репозитория.
2. Нажмите зелёную кнопку **New Issue**.
3. В заголовке напишите: `Набор: Имя Героя (Выпуск)`.
4. В текст сообщения вставьте колоду по шаблону:
   ```text
   Герой:
   Имя Героя

   Основная колода:
   3 Карта 1
   3 Карта 2
   ...

5. Нажмите Submit new issue. Мы сами проверим состав и добавим файл в нужную папку!
